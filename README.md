# TimeToCube ⏱️

Aplicación web desarrollada para registrar y gestionar tiempos de resolución de **speedcubing**.

El proyecto fue desarrollado completamente utilizando tecnologías web nativas, sin utilizar frameworks frontend como React o Vue.

## ✨ Características

- ⏱️ **Registro de tiempos:** permite registrar y gestionar tiempos de resolución.
- 👤 **Usuarios:** sistema de usuarios mediante Firebase.
- 🔐 **Autenticación:** gestión de autenticación y sesiones.
- 🎲 **Scrambles:** generación de scrambles para las sesiones de práctica.
- 🧊 **Visualización 3D:** integración de un cubo en 3D.
- 🍪 **Sesiones:** utilización de cookies para gestionar sesiones.
- 🔔 **Interfaz:** utilización de SweetAlert para mostrar mensajes y ventanas emergentes.

## 🛠️ Tecnologías

### Frontend

- HTML
- CSS
- JavaScript

### Servicios y librerías

- Firebase
- Cubing.js
- SweetAlert

## 🧊 Cubing.js

El proyecto utiliza **Cubing.js** para funcionalidades relacionadas con el speedcubing, incluyendo:

- Generación de scrambles.
- Visualización de cubos en 3D.
- Funcionalidades relacionadas con la práctica del cubing.

## 🔐 Usuarios y sesiones

Firebase se utiliza para la gestión de usuarios y el almacenamiento de información.

Además, el proyecto utiliza cookies para el manejo de sesiones.

## 🎯 Objetivo

El objetivo del proyecto era crear una herramienta web que permitiera llevar un registro de los tiempos obtenidos durante la práctica de speedcubing y proporcionar funcionalidades adicionales relacionadas con el cubo.
